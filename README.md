# Predictive Modeling Using Machine Learning

## Project Overview

This project demonstrates the implementation of Machine Learning algorithms to predict outcomes using the Titanic Survival Dataset. The workflow includes data preprocessing, exploratory data analysis, model training, evaluation, and performance visualization.

## Objective

To build predictive models that can accurately determine whether a passenger survived the Titanic disaster based on available features.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Jupyter Notebook

## Machine Learning Algorithms

1. Decision Tree Classifier
2. Random Forest Classifier

## Project Workflow

### Phase 1: Data Collection

* Imported Titanic dataset.
* Loaded data using Pandas.

### Phase 2: Exploratory Data Analysis

* Examined dataset structure.
* Identified missing values.
* Visualized feature distributions.

### Phase 3: Data Preprocessing

* Handled missing values.
* Encoded categorical variables.
* Removed unnecessary columns.

### Phase 4: Feature Selection

* Selected relevant features for prediction.
* Separated features and target variable.

### Phase 5: Model Building

* Trained Decision Tree model.
* Trained Random Forest modeL.

## Conclusion

The project successfully implemented machine learning techniques for predictive modeling. Random Forest outperformed Decision Tree and was selected as the final model due to its higher accuracy and robustness.
